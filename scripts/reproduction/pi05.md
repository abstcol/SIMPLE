# Official pi0.5: MuJoCo BendPick pilot

This tests `G1WholebodyBendPickMP-v0` with the original 36-D pi0.5 agent and
AMO controller, **not SONIC**. The six released SIMPLE pi0.5 checkpoints have
36-D action heads. The `pi05_zedmini13` SONIC training configuration exists,
but a matching public checkpoint was not found in the inspected official sources.

## Frozen inputs

- Psi0/OpenPI code: `805fcda9c9654e272be2a6673fe5290944fcfb04`.
- [Weights](https://huggingface.co/USC-PSI-Lab/psi-model/tree/74d7abaa61b51dfe4e95f539a83738c276ce27b2/openpi-05/G1WholebodyBendPickMP-v0/20000):
  `model.safetensors`, SHA256 `d60486bdf83665ff0345ea3a159e96a34c76110f151d2f883224e85d4d299227`.
- [Data](https://huggingface.co/datasets/USC-PSI-Lab/psi-data/tree/c8258285d134d0da644fdbf1a304988398fc3819):
  `simple/G1WholebodyBendPickMP-v0.zip` and `simple-eval/G1WholebodyBendPickMP-v0.zip`.
- Normalization uses the published training `meta/stats.json`, mapped exactly as
  the official `src/openpi/rewrite_norm_stats.py` recommends. This is not a recovered
  checkpoint-specific normalization file; the official weights folder omits one.

`serve_pi05.py` reuses the official model, input/output transforms and WebSocket
server. Strict weight loading is required. The official server appends the previous
torso command to the 28-D client state. No training or action remapping is added.
Use the upstream transformers replacement files in the **isolated pi0.5 environment**.
Set `TORCH_COMPILE_DISABLE=1` for eager inference, `JAX_PLATFORMS=cpu`, and project-local
cache paths. CPU JAX supports transforms; PyTorch CUDA 11.8 performs model inference.

## Commands (from the existing project directory)

```bash
export PSI0_SOURCE="$PWD/.tools/psi0-source/Psi0"
export PYTHONPATH="$PSI0_SOURCE/src:$PSI0_SOURCE/src/openpi/openpi-client/src:$PWD/src"
export OPENPI_DATA_HOME="$PWD/.cache/openpi"
export JAX_PLATFORMS=cpu TORCH_COMPILE_DISABLE=1 MUJOCO_GL=egl
.venv-pi05/bin/python scripts/reproduction/serve_pi05.py \
  --checkpoint data/checkpoints/pi05-bend-pick/model.safetensors \
  --stats data/pi05/G1WholebodyBendPickMP-v0/meta/stats.json

# Separate terminal: Python 3.10 overlay with websockets/msgpack, reusing existing sim packages.
export PYTHONPATH="$PYTHONPATH:$PWD/.venv/lib/python3.10/site-packages"
.venv-pi05-eval/bin/python scripts/reproduction/run_pi05.py \
  --data-dir data/pi05-eval/G1WholebodyBendPickMP-v0/dr-level-0 \
  --output experiments/reproduction/pi05/pilot-01 --episodes 1
```

The evaluator retains official initial layouts, 60-step stand stabilization,
50 Hz control, 400-step task budget and original success logic. Each paired trial
uses the same simulation seed and resets model noise to the same seed. The second
condition only replaces the ground visual material with uniform gray. Verify equal
saved initial qpos/qvel before comparing. This does not reproduce Isaac rendering,
and changes floor color as well as pattern; it is a floor-appearance diagnostic,
not evidence that all visual domain differences have been isolated.

Saved evidence: full head/front videos, every queried image, input states, output
action chunks, progress and failure records. Any failed baseline prevents interpreting
a second failure as a texture-induced loss of successful behavior. No successful
runtime validation is claimed until recorded below.
